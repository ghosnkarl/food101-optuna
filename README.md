# Food-101 Hyperparameter Optimization with Optuna + PyTorch

Automated hyperparameter search for image classification on the [Food-101](https://data.vision.ee.ethz.ch/cvl/datasets_extra/food-101/) dataset (101 classes). Uses [Optuna](https://optuna.org/) (TPE sampler + median pruner) to tune architecture, optimizer, scheduler, and augmentation across 7 model families. Configuration is managed with [Hydra](https://hydra.cc/).

## Installation

**Option 1 — automated (Linux/macOS/WSL):**
```bash
git clone <your-repo-url>
cd <repo-name>
bash setup.sh
```

**Option 2 — manual:**
```bash
git clone <your-repo-url>
cd <repo-name>
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

The Food-101 dataset (~5 GB) downloads automatically on first run via `torchvision.datasets.Food101`.

**Requirements:** Python 3.10+, CUDA optional (training runs on CPU but is much slower).

## Usage

### Single training run

```bash
# Train with the best ResNet-50 config (reproduces the results above)
python train.py --config-name resnet50_final

# Train with any model using default hyperparameters
python train.py model=resnet50
python train.py model=resnet18
python train.py model=efficientnet_b0
python train.py model=vit_b_16

# Override any hyperparameter on the fly
python train.py model=resnet50 training.n_epochs=30 dataset.batch_size=32
```

Results are saved to `results/<model>/` (checkpoint + `metrics.json`).

### Run Optuna hyperparameter search

```bash
# Search across all 7 model families (~100 trials, several hours with GPU)
python optimize.py

# Search a specific model only
python optimize.py experiments=[resnet50_finetune]
python optimize.py experiments=[resnet18_finetune,efficientnet_b0]

# Quick smoke test (fast, low-quality results)
python optimize.py optuna.n_trials=5 training.n_epochs=5
```

Per-study artifacts (trial history plot, parameter importances, CSV) are saved under `results/<study_name>/`. A comparison across all studies is written to `results/comparison/`.

### Visualize results in the Optuna dashboard

```bash
# Requires results/optuna_results.db (generated by optimize.py)
optuna-dashboard sqlite:///results/optuna_results.db
```

## Configuration

This project uses [Hydra](https://hydra.cc/) for configuration. Every parameter in `configs/` can be overridden from the command line using dot notation:

```bash
python train.py model=resnet18 training.n_epochs=30 dataset.augmentation.level=aggressive
python optimize.py optuna.n_trials=30 training.n_epochs=20
```

Each model config contains both fixed defaults (used by `train.py`) and a `search_space` block (used by `optimize.py` to define Optuna trial bounds). To add a new model, create a YAML in `configs/model/` and an experiment override in `configs/experiment/`.

## Models

| Model | Type | Backbone |
|---|---|---|
| `flexible_cnn` | From scratch | Configurable 3–6 layer CNN |
| `resnet18` | Transfer learning | ResNet-18 (ImageNet pretrained) |
| `resnet50` | Transfer learning | ResNet-50 (ImageNet pretrained) |
| `efficientnet_b0` | Transfer learning | EfficientNet-B0 |
| `mobilenet_v3` | Transfer learning | MobileNet-V3 Small |
| `convnext_tiny` | Transfer learning | ConvNeXt-Tiny |
| `vit_b_16` | Transfer learning | Vision Transformer B/16 |

Transfer models support differential learning rates (lower LR for backbone, higher for the classification head) and partial fine-tuning strategies (`freeze_backbone`, `fine_tune_from_layer`).
